Projects and Research

Asset Allocation via Machine Learning and Factor Models: An Empirical Evaluation of Portfolio Optimization Approaches
Bachelor Thesis, USI
May 2026
Supervisor: Prof. Patrick Gagliardini (USI, Swiss Finance Institute)

Python backtesting framework for multi-asset strategies, integrating Fama-French factors and Goyal et al. predictors via machine learning (Neural Networks, Elastic Net) for return forecasting, with Mean-Variance Optimization under Ledoit-Wolf shrinkage and turnover constraints.

PDF Repository
Commodity Assets as Portfolio Diversifiers: A Twenty-Year Empirical Analysis with DCC-GARCH, Markov Regime-Switching, and Machine Learning
Working Paper, Starting Finance Club USI - Quantitative Finance Division
June 2026
With Gianluca Ladelfa

Empirical study of main commodity futures as diversifiers against US equities over twenty-years. Combines DCC-GARCH for dynamic correlations, Markov regime-switching for macro-financial state identification, and a Random Forest with SHAP attribution for one-week-ahead forecasting. Portfolio optimization via CVaR minimization under Ledoit–Wolf shrinkage.

PDF Repository
Constructing Robust Investment Strategies: Regularization Techniques and CVaR Optimization
BSE Summer School Technical Project, Advanced Portfolio Management
July 2025
Supervisor: Prof. Javier Gil-Bazo (BSE)

Python framework for robust portfolio construction using LASSO/Ridge models, solving VaR-constrained portfolios via SciPy's SLSQP with 5-fold cross-validation, and a dual risk framework (Parametric vs. Historical Bootstrapping).
